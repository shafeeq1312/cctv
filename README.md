# CCTV & Security Solutions Website - Lucky Communication

Full-stack MERN (MongoDB, Express, React, Node.js) web application for **Lucky Communication** (Authorized CCTV Security & Hardware Solutions Store in Dindigul, Tamil Nadu).

## 🚀 Features
- **Responsive CCTV & Hardware Catalog**: Browse CCTV cameras, biometric systems, DVR/NVR recorders, and security accessories.
- **Instant Product Search & Filter**: Filter by stock availability, price, category, and specifications.
- **Automated Customer Enquiry Alerts**: Sends email notifications to admin (`ADMIN_EMAIL`) and generates instant direct links for WhatsApp (`+91 98765 43210`) & SMS alerts upon enquiry submission.
- **Admin Dashboard**: Full CRUD management for security products, categories, services, and incoming customer enquiries.
- **Image Protection**: Right-click and drag protection on CCTV product images.
- **Google Maps Integration**: Direct showroom location map and verified customer reviews.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS, Lucide Icons, Vite
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), Nodemailer
- **Authentication**: JWT Auth & Protected Admin Routes
